# Agent side-channel SoK — Defense Evidence Transfer

当前主文统一为三项 SoK 贡献，摘要、引言、Table 1、综合讨论和结论使用同一论证结构：

1. **记录级比较**：完整检查 39 条记录的 741 对；133 对涉及相关问题，其中 17 对支持来源限定的描述性比较。15 对同家族记录中，8 对涉及不同原语、目标或成本对象。
2. **配置级联合绑定**：351 个记录审计单元格把推断、效用和成本关联到具体配置。联合包由 CachePrune 的两条记录提供，对应一个家族、一个配置；不能将它解读为两个独立配置。
3. **部署决策**：82 家族的六轴 holdout 矩阵与决策表说明哪些证据支持所提部署变化，以及还需要测量什么。

## 审计分母与敏感性

Table 10 从共同的 33 条缓解记录展开排除、适用和绑定计数。S33 保留全部 165 个查询成员判断、六类相关记录对、26 次家族剔除及状态规则敏感性。全部原始标签不变；这些检查不等同于独立编码一致性。

- 推断—效用—成本的一个 CachePrune 配置在接受 P/? 的压力检查中保持不变，但剔除该家族后无正例。
- 匹配适应—推断的计数由严格 B 的 2/17 变为接受 P/? 时的 16/17，定位了需进一步核验的拟合／测试绑定。
- 同家族 8 个不兼容对分布于 6/11 个多记录家族；不把记录对当作独立样本。
