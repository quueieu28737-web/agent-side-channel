## 科学范围

真实 LLM 决定工具动作；网络测量是这些轨迹在本地 TLS 1.2 上的回放。程序条件复用同一轨迹，因此任务奖励相同是结构性质。这里有作者可执行的核验与重算，尚无外部独立复现。一个公开零售环境、一个可变模型别名、同模型用户模拟器以及未测量在线延迟/反馈效应是当前范围。

没有条件同时让两个目标达到预设的有限攻击套件标准。基线 shape-only 的退货目标单独满足标准；基线联合防御虽两个点估计均为 50%，区间上界仍为 60.6%/65.5%。这不削弱已测得的降幅，但不构成未知攻击者下的安全保证。
