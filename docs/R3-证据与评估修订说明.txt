第三轮审稿修订：证据表述与评估口径（2026-10-21）

本轮修改针对最新主稿与 E6/E7 评估，不把文字收缩视为补齐独立研究证据。

1. 95.7% 工具识别率
撤回将全体 582 次调用的样本内尺寸表纯度称为泛化识别率的写法。
新增按任务分组的五折 request-only 识别器和训练多数类基线；每个调用仅作一次测试。
与原 E7 使用 request+response 的训练折解码器分开报告。

2. 攻击器选择与区间
从 R2 保存观测重新拟合原固定攻击器集合，保存 184 组逐单位折外预测。
每个 bootstrap 抽样共同重采样任务，并在该次抽样中重新取攻击器最大 BA/AUROC。
不再复制点估计赢家的区间。个体攻击器区间继续作为个体结果保留。
这些为条件于固定折外预测的近似百分位区间，未包含重新训练、重叠训练折依赖、
特征/模型搜索与未知攻击风险，不能解释为安全上界。
计数规则的候选阈值仅由训练计数构造。

3. P5
计数/decoy cover 在 dispatcher 端已经泄漏，未满足“源端受保护”的前提。
目前只能支持泄漏跨加密观察投影持续存在，不能作为保护迁移失效的独立验证。

4. P7
没有一个已测试网络配置同时满足 cancellation 和 return 的有限攻击集合判据。
删除“只有联合方案接近随机”和“联合保护已建立”的表述。
26.3 倍字节、7.7 倍调用为单个配置的观测成本，不是必要成本下界。
DB equality 100% 仅支持隔离沙箱下的状态保持，不等于任务质量或授权保证。

5. 防御校准与任务留出
原防御模板、decoy 池和 framing cap 使用全部 115 个公开任务。
攻击器的任务留出不意味着防御已经接受未知任务评估。
新增训练折模板可行性审计；两个目标的划分都出现 5 个不同测试任务超出训练工具计数上限。
这不是训练专用模板/池/cap 下防御效果的新实验；这一缺口明确保留。

6. 贡献与证据强度
标题改为 Controlled Boundary Tests；摘要、引言、实验结论、Takeaway 与总结同步修改。
删除用“5 confirmed / 2 partial / 0 refuted”证明审计有效性的叙述。
七项判断均含 unresolved，且共享数据，没有独立正例、简单 checklist 或全 unresolved 基线，
不能估计区分能力或增量决策价值。原注册与历史 outcome JSON 保留原样，当前表重新判读。

E8 的旧单一攻击器区间不再用于当前主稿和补充表，改报诊断点估计。
替代规划器依然不能代表真实 LLM Agent；本轮未重算其套件最大值区间。

7. 复现和交付
修复 R2 只读验证中的 Windows 换行误报；历史预测在临时文件重算，不再覆盖来源文件。
修正 E6 session 计数被 E8 变量覆盖的问题。
当前分析在 experiments/sp2027-r3/，当前表使用 r3- 前缀；历史 R2 表不再作为当前表输入。
