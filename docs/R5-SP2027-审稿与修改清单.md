## 二、问题 1：新增的两个受控实验能否支撑核心贡献？

这两个实验指 E9 中的 **(a) 规则 prompt 对照** 和 **(b) 只用训练集校准的在线 shadow cover + 恒定分帧**。

**结论：R4 版本只是部分支撑。审稿人会抓住下面五点。**

1. **"降到 50.0%/50.0%"是攻击套件的下限，不是测量结果。** 套件里有一个多数类基线，它的 BA 恒为 0.5。防御后所有学习型攻击者在测试集上只有 43–45%，AUROC 低于 0.5。这说明训练集和测试集之间存在分布偏移，只有 5/7 个正例客户时，这种偏移会被放大。真正有信息量的是区间上界 63–66%，而摘要把点估计当成了结论。
2. **统计功效不足。** 取消有 5 个正例客户、退货有 7 个，所有防御格都是 inconclusive。
3. **规则对照没有机制解释，看起来像稻草人。** 读者会问：规则本来就不碰写调用，失败难道不是显然的吗？论文需要说明泄漏到底在哪里。
4. **规则+程序的退货 BA 是 64.1%，没有解释。** 审稿人会怀疑两者存在负交互。
5. **只有一个运行点（15.3× 字节）。** 没有前沿，也没有说明这个点是怎么选的，审稿人会质疑它能否部署。

**R5 的修订和结果（全部离线完成，使用已有的 690 条真实轨迹，不调用模型）：**

| 问题 | 实验 | 结果 |
|---|---|---|
| 1、2 | **E10 客户分组 5 折交叉拟合**：每折只用其他折重新校准防御、重新训练攻击者 | 未防御 91.7/85.5；E9 点 60.5/52.1；配对降幅 −31.2 [−41.6, −21.5] 和 −33.4 [−41.0, −21.5] |
| 4 | E10 配对对照 | 分桶防御下规则减基线为 +1.2 [−7.0, 7.5] 和 −2.0 [−7.4, 4.2]。64.1% 没有复现，交互效应不存在 |
| 5 | **E11 六点前沿 + 只用训练集选点** | 1024 字节分桶：52.2/52.7，成本 12.4×，比恒定分帧的 19.8× 低 37%，泄漏也不更高。上界 60.5/60.2，正好落在 60% 阈值上；快照网格上为 59.2/58.3，达标。按训练集规则选中分桶点后，在冻结的 46 个测试任务上成本为 9.8×（原为 15.4×），点估计为 53.2/58.4 |
| 3 | **E12 泄漏定位** | 只看写调用：91.7/84.9；去掉写调用：55.2/59.9。规则把读序列从 74 种降到 62 种，写序列不变（37 对 36）。只覆盖写调用的防御仍然泄漏（53.5/56.1，三种配置都没有通过内层选点） |

**修订后**：两个对照实验从"现象"变成"机制 + 剂量"。规则失效是因为意图存在于写调用里；程序整形之所以有效，是因为它覆盖了完整的调用剖面和大小；成本可以沿前沿调节。

## 三、问题 2：现在创新性和实证充分了吗？

**创新性**

- 已有贡献：82 个家族、39 条记录的结果记录库；R1–R9 审计；三态判定（compatible / incompatible / unresolved）。
- 本轮新增、可以写进摘要和贡献的发现：
  1. **写调用定位原则**：在使用工具的 Agent 中，意图元数据主要由改变状态的调用及其大小携带。这条原则可以推广到其他工具型 Agent，并直接给出防御设计次序。
  2. **规则 ≠ 隐私**：工作流标准化作用在读调用上，触及不到泄漏源。
  3. **分帧是主要的成本杠杆**：仅分帧选择就让成本在 12.4× 和 19.8× 之间变化，而且更便宜的分桶点泄漏也不更高。
- 审稿人仍可能认为审计本身是"已知原则的应用"。本轮把这句话从自贬的写法改为正面定位："贡献是这些原则在 LLM/Agent 防御上的可追溯应用，以及它们支撑的跨边界测量。"

**实证**

- 足以支撑："训练集校准的在线整形在真实 Agent 上大幅降低意图推断，成本可量化、可调节。"
- 仍不足以支撑：跨模型/跨基准的泛化、在线时延、对未知攻击者的保证。正文只在 9.3 节统一交代一次，不在摘要和结论里反复让步。

## 六、写作策略说明

按"抓大放小、突出优势"的原则，本轮做了三件事：
- 让摘要、引言和结论以已经证实的发现开头，删去重复出现的让步句。
- 把所有限定集中到 §9.3，每条只写一次。
- 把 "reward preserved by construction" 这类看似弱点的事实，改写为它本来就具有的设计属性（planner-transparent）。

有两类内容我们没有删除，因为删除会成为审稿人的拒稿理由：
1. 完整队列上分桶点的上界正好落在 60% 阈值上（§8.5 一句话）。
2. E11 选中点在小测试集上点估计升高（§8.5 一句话，表述为成本与泄漏的权衡）。

审稿人会自己算出这些数，主动、简短地交代反而更可信。
