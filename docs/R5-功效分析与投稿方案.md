# R5 功效分析、写作思路与实施方案

状态:规划文档,未包含新实验数据。基于 2026-10-23 提交 f0fb3d2 与 main.pdf。

## 1. 现状问题

1. E9 测试集仅 5 个取消正类客户、7 个退货正类客户。Clopper-Pearson 精确 95% 下限:5/5 为 0.478,7/7 为 0.590。
2. 联合防御点估计 50%,但上界 60.6%/65.5%,未达预设标准(上界<0.60)。
3. 单环境、单模型别名,用户模拟器为同一模型。
4. 攻击者集合偏弱,缺少序列神经网络与知道防御算法的自适应攻击。
5. 人工标注独立性不可验证。
6. 仓库根目录堆积历史大文件;提交元数据可能暴露作者身份,不利于双盲。

## 2. 功效计算(正态近似,未计多攻击者取最大值带来的膨胀)

要使真实 BA=0.5 时 95% 区间半宽不超过 w,正类数 n_pos 需满足 1.96*0.5*sqrt(0.25/n_pos+0.25/n_neg)<=w。

| 负:正比 | w=0.10 | w=0.075 |
|---|---:|---:|
| 1:1 | 49 | 86 |
| 2:1 | 37 | 65 |
| 3:1 | 33 | 57 |

结论:每个目标至少约 33 个正类客户(按客户聚类),当前为 5 和 7。

## 3. 论文写作思路

- 定位:以 SoK 为主,真实 agent 测量作为"检验框架"的案例,而不是并列贡献。
- 主线一句话:论文级阅读会得出错误的防御复用结论;绑定接收视图、执行边界、评估条件后结论改变。
- 每个审计发现对应一个可证伪的转移主张,并用实验证实或证伪(缓冲填充成本不能给流式定价;只读掩护不能等同于活动 GUI 掩护;D0 与 D2 对比)。
- 摘要只保留 4-5 个数字;未达标的结果写成"点估计加上界"。
- 术语压缩:R1-R9 合并为 5-6 项;NR-R/A/V 改为三色标记;E/S/P 编号减少。
- 声明性防御语句集中到一节"Scope and Non-claims",正文贡献陈述保持肯定。
- 与 website fingerprinting 防御(Tamaraw、FRONT 等)做明确类比,标出哪些结论为新。

## 4. 实施方案

阶段 A(第 1 周)
- 修改摘要与结论措辞;冻结模型版本或保存响应缓存。
- 匿名化:新建匿名镜像;清理提交作者元数据;根目录历史包移入 archive/ 或 Releases。

阶段 B(第 2-3 周,需联网与模型 API,不能在无网沙箱完成)
- 扩大测试集至每目标 >=33 个正类客户,并保持客户不重叠。
- 增加第二环境与第二模型;用户模拟器使用不同模型。
- 增加序列神经网络攻击者与自适应攻击(攻击者知道防御算法并在防御后数据上重训)。
- 预注册:先提交分析脚本与判定标准,再采集测试数据。

阶段 C(第 3-4 周)
- 独立人工标注 >=100 条,盲化,报告 alpha 与裁决流程。
- 对 396 条被排除记录做全量或分层复核,报告遗漏率。

阶段 D(第 5 周)
- 内部模拟审稿;核对 S&P 2027 关于 AI 辅助写作与双盲的披露要求;整理 artifact。

## 5. 验收标准

- 联合防御两个目标的 95% 上界均 <0.60(按客户聚类自助法,含多攻击者最大值)。
- 两个环境、两个模型方向一致。
- 外部检验显示三项检查相对简单清单有可测增益。
- 仓库扫描无作者身份命中。

## 6. 风险

- 扩大样本后上界仍可能不达标;此时应将结论降为"显著降低但未消除"并给出成本曲线。
- 若无法完成第二环境,需把声明范围明确限定为单一环境。
