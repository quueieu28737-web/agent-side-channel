## 核心结果

| 条件 | 取消 BA | 退货 BA | 任务完成率 | 字节倍率 | 调用倍率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 基线 | 96.7% | 93.4% | 82.1% | 1.00 | 1.00 |
| 规则 prompt | 96.7% | 92.8% | 78.0% | 1.00 | 1.00 |
| 程序防御 | 50.0% | 50.0% | 82.1% | 15.33 | 3.83 |
| 规则 + 程序 | 50.0% | 64.1% | 78.0% | 15.70 | 3.90 |

BA 是固定攻击套件的最大平衡准确率，区间见主稿和 S14。程序防御为在线 shadow cover 加恒定分帧，倍率相对同一 prompt 的原始传输。

论文重点强调：真实 Agent 的任务完成率并不阻止元数据泄漏；规则 prompt 达到 96.7% 机械工作流合规率，但不能替代程序层保护；训练限定的在线整形大幅降低本次攻击点估计，并给出明确成本。

## 结论范围

这是单模型、单公开基准的内部评估，截止时仍有 27 次计划运行未完成。完整任务纳入规则避免组间缺格，但完成顺序可能影响任务组成。测试只有 5 个取消正例客户、7 个退货正例客户，区间较宽，不宣称消除泄漏。

真实模型生成 Agent 轨迹，网络测量为本地 TLS 回放。程序条件复用原轨迹，因此奖励相同不能证明在线延迟和反馈没有代价。规则与程序组合的退货 BA 高于程序单独使用，但配对区间跨零，不宣称显著变差。

独立外部复现和人工验证仍未完成；论文将可执行核验与外部独立验证明确区分。
