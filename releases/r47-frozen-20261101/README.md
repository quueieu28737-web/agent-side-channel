# R47 paper and supplement

This release contains the revised paper, its supplement, and a source bundle
for those two documents. The source bundle does not include the experimental
raw data or a complete research-artifact archive. The existing historical
experiment package remains a separate snapshot.

The literature map is a bounded, retrospective synthesis. Source identity,
eligibility, and coverage limitations are described in the paper. The
supporting experimental results and their selection limits are reported in
the paper and supplement.

The source-bundle scan covers the paper and supplement only. This repository
is a named public location and is not an anonymous submission service.
