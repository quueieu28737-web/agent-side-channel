\subsection{Origins, receiving projections and threat polarities}
Across all \FinalCore{} core families in our unified repository, 38 study inherited runtime, serving or hardware channels (Origin~B) and 20 study agent-workflow channels arising from orchestration, tool dispatch, browser navigation and multi-agent protocols (Origin~A; Table~\ref{tab:core-family-map}). Signal generation origin is distinct from both receiver location and threat polarity. The full map makes these distinctions visible for each core family.

\paragraph{Type~I: Confidentiality and privacy channels}
Inherited serving and transport attacks infer confidential prompts or topics from packet lengths, inter-packet timing, KV-cache sharing and hardware contention. Weiss reconstructs token sequences from encrypted packet lengths, whereas NetEcho recovers conversation semantics after application-layer re-chunking \cite{weiss2024prompt,netecho2025}. Whisper Leak classifies prompt topics from streaming traffic; Time Will Tell uses total completion duration \cite{whisperleak2025,timewilltell2024}. Chosen-request cache attacks probe shared KV prefixes or semantic caches via timing oracles, while CPU-cache, GPU memory-barrier, attention-sparsity and page-migration attacks exploit co-resident hardware channels \cite{promptpeek2025,earlybird2025,inputsnatch2024,spliceleak2026,spillbeans2025,gu2026behindbars,chen2026sparleak,jo2026sparseety,nazaraliyev2026page404,alhalawani2026physicaledge,hadad2026shape}. In split learning/inference, SplitDecoy shows that even when forward activations are masked with decoys, the zero/nonzero row support of returned backward gradients exposes real token positions \cite{politis2026splitdecoy}. At the workflow layer, WRA infers private user functional intent and personal traits from visited domain sequences \cite{jeong2026wra}, AgentTell uses probe websites to extract behavioural secrets \cite{shahriar2026agenttell}, and routing-metadata attacks infer sensitive prompt topics from model/expert routing choices \cite{chen2026routingmetadata}.

\paragraph{Type~II: Provenance, model and identity attribution}
Type~II groups studies by an attribution target: \emph{which model, agent harness or user} produced a trace; such attribution can also raise Type~I confidentiality concerns. UI Traces attributes browser-agent identity across 14 models from own-site DOM/JS event sequences \cite{uitraces2026}; FP-Agent combines behavioural traces with static browser attributes \cite{wang2026fpagent}; AgentPrint and the cloud traffic benchmark classify workflows or model families from network flows, while Whose Agent Are You? uses browser-visible fingerprints \cite{agentprint2025,kang2026whoseagent,pouryousef2026traffic}. LLM-WFIN combines interrupt and packet traces to infer the visited LLM website and interaction-content type \cite{jiao2025llmwfin}. AgentProv audits tool-use provenance, Lidar fingerprints agent harnesses from action roles and timing, and Cross-Campaign Attribution links asynchronous attack agents \cite{wang2026agentprov,wang2026lidar,park2026crosscampaign}.

\paragraph{Type~III (Bot-detection evasion) and Type~IV (Authorized diagnostics)}
Type~III studies evaluate human--agent distinction \cite{fayolle2026webagents,zhu2026turing}. Here the threat polarity is inverted relative to Type~I privacy: in AHB \cite{zhu2026turing}, the platform detector is a defensive anti-automation control, while ``action humanization'' is an evasion mechanism applied by the agent. Finally, five core families are Type~IV authorized operator diagnostics: ClawGuard, cycle detection, LumiMAS, LLM-serving root-cause analysis (120 controlled fault injections) and MIRAGE (internal residual-stream hooks) \cite{gan2026clawguard,george2025cycles,solomon2026lumimas,scheinert2026rca,revankar2026mirage}.

\subsection{Relationship to prior systematizations}
Prior surveys establish compound-system threat models and confidential-computing boundaries. Banerjee et al.\ categorize cross-layer compound AI threats under MITRE tactics; Forough et al.\ distinguish TEE isolation boundaries from side-channel resistance and note that inference protections need not cover agent memory or action coordination \cite{banerjee2024compound,forough2026secrets}. Kotevska et al.\ propose a six-element privacy contract (asset, observer, channel, permitted disclosure, guarantee, evidence) with composition conditions framed as formal conjectures \cite{kotevska2026privacyfoundations}, while classical website-fingerprinting works establish bandwidth/latency bounds for transport shaping (Tamaraw, WTF-PAD, FRONT, Walkie-Talkie) \cite{cai2014systematic,juarez2016wtfpad,gong2020front,wang2017walkietalkie}. Our distinct contribution is the populated 82-family / 39-record repository, the nine-item comparability audit, and pre-registered tests of the transfers it flags, using loopback TLS replays and a pinned stateful tool simulator. Website-fingerprinting defenses already show that per-packet padding leaves counts and that constant-shape shaping is expensive \cite{cai2014systematic,juarez2016wtfpad}. E5 measures how that known property invalidates a specific cost transfer for LLM token streams, without claiming it as new.
