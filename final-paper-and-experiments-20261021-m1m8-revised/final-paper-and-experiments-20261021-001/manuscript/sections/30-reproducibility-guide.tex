\section{Reproducibility and Planner-Visible Equivalence}\label{app:search}\label{app:notation}\label{app:equivalence}
\paragraph{Artifact organization}
The archived reproducibility package has four logical modules: the source ledger and family audit; transport experiments; stateful tool-dispatch experiments; and the complete real-agent study. A machine-readable module index resolves these names to the immutable source files, predictions and verification entry points. The README supplies environment versions, checksums and commands. The current paper uses the complete 690-run cohort; earlier releases retain their original membership and results for provenance.

The source module contains all 82 family records, the 39-result ledger, all 180 audit cells, search reconciliation and coding columns. The real-agent module contains the 414/276 training/test split, frozen calibration, model decisions, sandbox scores, 2,760 TLS sessions and saved attack predictions. Offline reconstruction reproduces the fitted-attack results and intervals without additional model calls. The real-agent module also includes customer-cross-fitted analyses, training-fold operating-point selection and an oracle write-call ablation (E10--E12, Supplement S15). Their analytic TLS record model is checked against the measured sessions. E13 adds 4,140 live tool sessions, observed record-arrival timestamps, pre-test frozen attack models and complete tunnel controls (S19). The paired program contrasts reported in the current paper are a post hoc analysis of those saved predictions, using the same 2,000 customer-cluster draws and recomputing the suite maximum for each condition in each draw.

\paragraph{Equivalence invariant and assumptions}
Let $s_t$ be live tool state and $H_t$ the planner-visible sequence of messages, actions and tool responses. A real action $a_t$ produces $(s_{t+1},o_t)=T(s_t,a_t)$. The defended dispatcher forwards $a_t$ unchanged and executes cover transitions only on a separate state $s_t^{\rm sh}$, suppressing their responses. With the same initial live state, deterministic simulator tools and the same realized real actions, cover cannot change $s_{t+1}$ or $o_t$. Induction on real-action steps gives
\[
 s_t^{D}=s_t,\qquad \pi_{\rm plan}(D(H_t))=H_t.
\]
Framing preserves application payloads and end-of-episode flushing adds only hidden shadow transitions. This is equality of the logical planner transcript. It assumes no timeouts, shared-state side effects or timing-dependent tool behavior; equality of independent model samples is not required. Beyond E13's local tool-loop measurements, a fully interactive deployment would additionally need to establish that wall-clock delay and shared resource effects do not change task execution.

The frozen dispatcher copies each real-call record verbatim into the defended stream. Executable checks match the real-call projection and original scoring fields across all 690 trajectories and four program conditions. Shadow execution and wire-byte accounting are separately reconstructed by the original full-cohort verifier. Reward equality therefore expresses the isolation invariant; call and byte ratios quantify the transport intervention on that fixed workload.

\paragraph{Reading the main tables}
The corpus map reports signal-generation and receiving layers separately. The per-family audit distinguishes bound, partial, unreported, unverified and inapplicable evidence. These statuses preserve source scope: an unverified binding identifies a comparison obligation rather than declaring an experiment absent. In the real-agent table, point BA, paired BA reduction and the absolute finite-suite criterion answer different statistical questions; all intervals condition on the saved fitted attackers.
