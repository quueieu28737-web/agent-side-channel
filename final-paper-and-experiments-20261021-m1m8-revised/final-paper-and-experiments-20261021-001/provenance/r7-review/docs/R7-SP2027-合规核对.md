# R7：S&P 2027 官方要求核对

核对日期：2026-10-24。依据：[官方 CFP](https://sp2027.ieee-security.org/cfpapers.html)。这是一份投稿准备核对，不是已经完成 HotCRP 投稿的声明。

| 项目 | 官方要求 / 本轮处理 | 状态 |
|---|---|---|
| SoK定位 | 标题以SoK:开头；价值取决于系统化视角，而非新实验数量。主文新增RQ→Finding→Evidence表并明确结果记录/跨边界比较的洞见。 | 文稿修改 |
| 页数 | 正文最多13页；通常总计18页（参考文献/附录最多5页），SoK参考文献不计页数。仍采用更保守的13页正文/总计≤18页检查。 | 最终PDF验证记录为准 |
| 模板 | US Letter、IEEEtran 1.8b、conference,compsoc；不得修改页边距、字体或行距规避页数。 | 源码/PDF检查 |
| 匿名 | 不写作者、单位、致谢身份；提交时需匿名工件，不应直接提供有身份和开发历史的GitHub仓库。 | PDF自动检查；匿名托管仍需作者完成 |
| 附录 | 超过正文页限的内容须明确标注；审稿人无义务阅读附录。主文恢复E5全部cell、E6主表，保留E12消融和新结果最小支撑。 | 文稿修改 |
| Artifacts | 官方强烈鼓励匿名工件；论文截止后不得更新提交的工件版本。未找到单独强制名为“Open Science”的正文小节要求；加入复现/工件说明。 | 本地归档可验证，提交链接仍需作者填写 |
| Ethics | HotCRP登记必须完成Ethics Considerations字段；录用后camera-ready需对应小节。补充诱饵执行对租户费用、供应商容量和账户数据的影响及本地隔离措施。 | 文稿已有；HotCRP未代填 |
| AI披露 | 允许AI作为研究对象或写作辅助，但须披露并解释动机，作者负责准确性。明确初始AI提取、作者源定位复核、AI代码/写作辅助；不称独立人际κ。 | 文稿修改 |
| 漏洞披露 | 新发现真实部署漏洞时须说明披露流程，通常不晚于rebuttal；当前实验限本地公开模拟器，不虚构vendor disclosure。 | 范围已说明 |
| 作者/COI/ORCID | 作者列表及ORCID、COI需在摘要登记时完整；每人每轮最多6篇。 | 作者操作，不由代码验证 |
| 第二轮日期 | 摘要2026-11-10，全文2026-11-17，均23:59:59 AoE。旧方案里的11/11截止推测已过时；以官网为准。 | 官方已核对 |
| 最终上传 | 作者须至少提前24小时有稿件提交；本轮未执行HotCRP注册/上传。 | 尚需作者执行 |

公开开发仓库的提交不等于匿名投稿工件的发布。最终交付报告将分别给出PDF/数据验证与仍需作者完成的投稿动作，不混为“全部合规已完成”。
