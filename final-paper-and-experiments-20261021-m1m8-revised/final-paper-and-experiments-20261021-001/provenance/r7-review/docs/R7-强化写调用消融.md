# R7 强化写调用消融

本独立事后补充延伸旧 E12 的 oracle 信息消融，不改旧表或原始 690 个 Sol episode。标准提示为 baseline，rules 为独立规则组。先完成并通过 R7 crossfit 的 60 包精确验证，再冻结独立 `sp2027-r7-localization/PLAN.md`、协议与源/输入哈希后训练。

使用原 R5 客户五折，在每折其余客户上拟合完整 9 个旧 network 攻击、固定 50 epoch / 512 head-tail CNN 和 k-FP 风格叶指纹三近邻，共 11 攻击。两种 oracle 视图分别只保留真实写调用交换（writes_only）或删除全部写调用交换（no_writes，即 reads only）；两提示、两目标、五折共 40 包。完整视图直接引用已验证 R7 crossfit 的 undefended 折外预测，以协议中的原始哈希固定。

按旧 E12 `session/VIEWS` 精确过滤真实调用后，使用原解析 TLS 模型重建方向/长度；oracle 依赖真实调用名，因此是信息定位诊断，不是观察者可直接部署的隐藏防御。没有新增模型调用或网络采集。第三时间列恒为零，mask 仅表示记录存在；不生成或伪造时间。没有防御校准适用于这些未防御 oracle 视图。

每次客户聚类 bootstrap 都在完整 11 攻击上重新选最大值，使用 2,000 次共同抽样；配对差定义为完整视图最大 BA 减去过滤视图最大 BA。区间以已拟合攻击为条件。本补充不是预注册或确认性证据。

所有模型分别压缩保存，逐文件小于 100 MiB。可移植 `verify.py` 检查模型重载预测、完整旧 suite 重训预测、原始客户分折和零交集、原始 oracle 调用/记录过滤、重复键、标签和零时间列。新协议采用包内相对路径并核验 SHA，不改旧 crossfit 冻结文件。

`table.py` 输出 baseline 主文两行 LaTeX，`--detail` 输出完整 S21 表。结果、每攻击区间、并集区间、赢家、配对差和保留信息比例将保存在独立目录的 `detailed_results.json` / `RESULTS.md`；不修改主稿。

## 观测结果

标准提示 baseline 的主表两行（完整 / reads-only / writes-only）：cancel 最大 BA 分别为 0.916666667 [0.820512821, 1.000000000]、0.627815960 [0.545603098, 0.753332767]、0.916666667 [0.820512821, 1.000000000]；return 分别为 0.854919679 [0.766722274, 0.934030428]、0.599021084 [0.522259884, 0.717849460]、0.849272088 [0.787884838, 0.940013369]。

baseline 完整减 reads-only 的配对 BA 下降：cancel 0.288850706 [0.107157382, 0.419281200]，return 0.255898594 [0.109922322, 0.353804091]。完整减 writes-only：cancel 0.000000000 [0.000000000, 0.000000000]，return 0.005647590 [−0.069063756, 0.025155255]。区间仍按每次重采样的 11 攻击最大值计算；零分位数区间不表示所有模型或所有 bootstrap draw 完全相同。

两个提示组的 reads-only 区间均跨过原 BA 0.60 判断边界，不能据此断言读调用已消除可区分信息。写交换保留了大部分完整视图的观测区分能力；此结论限于 oracle 过滤和已评估队列。全部 12 行的 BA 赢家仍来自旧攻击；新增 CNN/k-FP 被纳入每次最大值重选，不能因为它们未获胜而从攻击并集移除。

全部精确复现审计已通过：40 个独立模型包、2,760 条新折外记录、30,360 个攻击分数组合；原客户交叉为零、重复键为零，原始调用/解析 TLS 过滤逐会话完全一致。已另核对完整视图引用与原 E12 full 会话完全相同，以及 reads-only / writes-only 的保留调用和 wire 比例相加为 1。最大模型包 884,865 bytes。`main_table.tex` 与 `s21_table.tex` 已生成，逐文件哈希见 `artifact_manifest.json`。

## 可复现依赖闭包勘误

为匹配实际 R5 retail/Tau 和 learners→R7/R6 共享导入链，增加未冻结的 `dependency-closure.json`、独立 `dependency-path-map.json` 与原 manifest 锚定检查。28 项闭包中 4 个 R6 Python 文件已在 L 原协议直接绑定，其余项补齐原依赖枚举缺口。源/数据 SHA 均须与原 R4/R6 manifest 的具体表键一致；不得任意新增路径。R4 runtime 还须与原 episode fingerprint 的 SHA 一致。

原 L/C 协议、原 verification 收据、全部数据/模型/预测/结果均保持字节不变。新增 `dependency-verification.json` 记录通过的闭包审计；它和原 `verification.json` 是两个并列收据。verify 在 import 实验模块前检查闭包，不需要重训。本勘误只涉及仓库源/数据依赖枚举，第三方运行环境仍须匹配详细结果中的版本。

最新依赖闭包从 28 扩充为 36 项，补入 R4 split/protocol/runtime 和 5 个指纹输入的原 manifest SHA 绑定，包含非 Python 数据。原协议和 numerical verification 字节均不变；独立闭包收据已重新通过。新增 requirements.txt 固定实际 sklearn 1.9.0 及其余运行版本，README 提供通用 venv/pip/verify，不要求 ignored 开发依赖路径。
