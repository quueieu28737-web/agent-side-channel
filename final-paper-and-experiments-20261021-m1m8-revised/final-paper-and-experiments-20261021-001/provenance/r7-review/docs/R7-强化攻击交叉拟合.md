# R7 强化攻击交叉拟合

本补充针对原始 690 个 Sol episode 的已知队列进行事后分析。它不属于预注册或确认性评估。结果保存在 `experiments/sp2027-r7-crossfit/`，不修改旧 R5 结果。

使用 R5 原始客户分组、分层五折算法和随机种子。每折的模板、捐赠请求、长度上限与所有攻击模型均仅使用其余四折的客户。按 baseline / rules、cancel / return、undefended / jointconstant / jointbucket1024 分别训练，最终汇总折外预测。

网络视图保留 `r5lib.attack_suite(extended=True)` 的全部旧攻击，并加入固定 50 epoch、512 条 head/tail 记录和聚合池化的可训练一维 CNN，以及随机森林叶指纹三近邻的 k-FP 风格攻击。后者是借鉴叶指纹距离的实现，不等同于原始 k-FP 特征实现。

R5 使用原有解析 TLS 模型重建记录，记录只有方向与长度；本补充未新采集网络会话。将 c2s / s2c 映射为 +1 / −1，将第三列严格置零；没有测量时间，也没有生成时间信号。CNN 第三通道因此恒为零，第四通道只表示记录存在性。所有攻击只获得方向与长度及由此推导的特征。

冻结的 `protocol.json` 记录协议和源代码哈希。第一次执行在方向字符串转浮点时失败，未保存任何完整 cell 的模型包或结果（旧 suite 的中间拟合随失败进程丢弃）；该初始协议保存为 `protocol_initial_failed.json`。修正方向适配后，重新冻结协议并运行。`inputs_manifest.json` 在第一个成功 cell 生成之前固定输入 episode 与旧 Python 源码哈希。

每个折、条件、提示和目标的压缩包保存已训练旧模型、新模型、训练及测试会话、完整攻击分数。`predictions.json` 保存全部 4,140 条目标/条件级折外记录。客户聚类 bootstrap 使用 2,000 次共同重采样；每次重采样重新在全部旧攻击和两个新攻击上选取最大 BA。区间以拟合后的攻击为条件，不包含训练算法不确定性。配对下降定义为 undefended BA 减去防御后 BA。

可移植预测复现入口（仓库根目录，PowerShell；将 Python 路径替换为匹配版本的本地解释器）：

```powershell
$env:PYTHONPATH='revision-preview/r7-deps;revision-preview/r3/deps'
& 'C:/Users/Administrator/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' 'final-paper-and-experiments-20261021-m1m8-revised/final-paper-and-experiments-20261021-001/experiments/sp2027-r7-crossfit/verify.py'
```

`verify.py` 对持久化模型预测、旧 suite 重训预测与保存预测执行逐数组精确相等检查，核对客户分折、训练/测试零交集、捐赠者训练来源和零时间列。精确数值表将写入该实验目录的 `RESULTS.md` 与 `results.json`。



冻结的 protocol 与 inputs_manifest 保留原开发机的绝对路径，未被静默改写。verify.py 依据 portable-path-map.json 显式移除固定包根前缀，只允许将记录路径按原相对位置重定位到当前包的 experiments/ 内，并逐个核验原 SHA。冻结 run.py 的协议等值检查包含原路径，因此不能声称换 checkout 后直接执行 run.py 可恢复训练；可移植入口是 verify.py。新训练应另建独立目录和协议。当前开发仓库含历史本机路径，不是匿名归档。


## 本轮精确结果（独立规则组 rules）

11 攻击完整并集的 BA：cancel 未防御 0.907407407 [0.815432423, 0.988906250]；联合常量 0.587533410 [0.521251323, 0.716052169]；联合 1024 分桶 0.569014891 [0.501560245, 0.712054646]。return 对应为 0.854919679 [0.765844089, 0.935900673]、0.594001004 [0.542363316, 0.688091819]、0.526669177 [0.500000000, 0.650045518]。

常量防御两目标的点估计赢家均为旧 D2 logistic；分桶防御 cancel 赢家为新增 CNN，return 赢家为新增 k-FP 风格攻击。未防御两目标的 BA 赢家均为 network_decode_count_rule。常量和分桶防御在两个目标上的区间均不能满足原 BA 上界 < 0.60 的要求，均判为 inconclusive；这不是安全证明。

配对 BA 下降（未防御减防御）：cancel 常量 0.319873998 [0.131408074, 0.442141529]，分桶 0.338392516 [0.141582153, 0.457688492]；return 常量 0.260918675 [0.111419718, 0.366096881]，分桶 0.328250502 [0.189721509, 0.397854091]。常量 wire 19.884291254×、分桶 12.445245696×；两者 calls 均 5.038043478×。

完整 baseline/rules、两目标、三条件的每攻击 BA/AUROC 与区间、suite 最大值与区间、配对差、成本和赢家见该实验目录的 `detailed_results.json`、`RESULTS.md`。`table.py --prompt baseline` 输出主文标准提示组表片段，`--prompt all` 输出完整表；不会改主稿。


完整验证已通过：60 个模型包、4,140 条目标/条件级折外记录、45,540 个攻击分数组合；持久化预测与旧 suite 全量重拟合预测逐数组精确一致，客户训练/测试零重叠。最大单文件 4,992,863 bytes，所有文件均小于 100 MiB。`main_table.tex` 采用标准提示 baseline；独立规则组另存 `rules_table.tex`，完整两组表为 `all_results_table.tex`。`artifact_manifest.json` 记录逐文件哈希和大小。

## 可复现依赖闭包勘误

独立搬迁检查发现初始 source/input 清单遗漏 R5 retail/Tau 与 R6 helper 的导入闭包。新增未冻结补充 `dependency-closure.json`，只列出 28 个已由原 R4 runtime 或 R6 attacker/frozen manifest 绑定 SHA 的源/数据文件；`dependency-path-map.json` 只允许这些路径与 3 个原锚点。`dependency_check.py` 还验证 R4 runtime SHA 与已核验原 episode fingerprint 一致，以及 R6 frozen 链一致。两个目录的新增 `dependency-verification.json` 均通过。

原 protocol、inputs、run、模型、结果及 `verification.json` 保持原字节。特别是 C 的 `verification.json` 与原 path-map 已被下游 L 协议 hash 绑定，因此新增独立补充文件和闭包收据，不改旧文件。verify 入口先检查受限依赖闭包，再进行原精确预测审计。原数值验证收据与新增闭包收据应并列检查；该勘误不构成重训或新结果。

最新闭包补齐为 36 项：在初次 28 项导入依赖之外，逐项纳入搬迁执行实际读取的 R4 split、protocol、runtime_manifest 本体和 5 个 inference-fingerprint 文件（含 txt/schema，非仅 Python）。对应原 runtime 的 split/protocol 标量 SHA、原 5 文件键和已绑定的 runtime SHA；单一固定别名只把原 sp2027-r4 文件定位到 snapshot。两份 dependency-verification 收据通过，原 numerical verification 收据未改。

C/L 已增加实际 requirements.txt（NumPy 2.5.4、SciPy 1.18.1、scikit-learn 1.9.0、joblib 1.6.0、torch 2.14.1+cpu，含 PyTorch CPU index）和通用 Python 3.12 venv/pip/verify 命令；不依赖 ignored revision-preview 目录，不混用 Luna 的 sklearn 1.9.1。
